# deep_learning_PA1
Repositório dedicado ao programming assigment da disciplina de aprendizado profundo do curso de Ciência de Dados e Inteligência Artificial. 


## Ambiente

Este projeto usa `uv`. Escolha o modo de instalação conforme seu hardware:

# Com GPU NVIDIA (CUDA 12.x/13.x):
uv sync --extra gpu

# Sem GPU (CPU-only):
uv sync --extra cpu
